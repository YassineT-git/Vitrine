# Logos des établissements

- `polytech-paris-saclay.svg` : tracés du logo Polytech, extraits du [fichier vectoriel officiel](https://www.polytech.universite-paris-saclay.fr/sites/default/files/media/2020-04/POLYTECH-h-rvb.svg).
- `iut-orsay.svg` : tracé du nom IUT d’Orsay, extrait du [fichier vectoriel officiel](https://www.iut-orsay.universite-paris-saclay.fr/sites/default/files/media/2020-04/IUT-D-ORSAY-h-rvb.svg).
- `universite-paris-saclay.svg` : [logo vectoriel officiel de l’université](https://www.universite-paris-saclay.fr/sites/default/files/media/2019-12/logo-ups.svg).
- `lycee-villaroy.jpeg` : logo fourni par Yassine, 200 × 200 px, affiché à 64 × 64 px.

Les tracés des SVG sont conservés. Le logo de l’université reste séparé de celui de chaque école pour composer la ligne sous les dates. Le noir et blanc et l’adaptation au thème sombre sont définis dans `css/styles.css`, section `.education-logos`.

Pour remplacer un logo, garder son nom de fichier ou modifier son chemin dans `parcours.html`.
